\# Requisitos Funcionais



Esta pasta contém o documento de especificação dos requisitos funcionais do projeto Agente Inteligente para Análise da Gestão Financeira Municipal.



O documento apresenta os requisitos RF01 até RF10:



\- RF01: Controle de perfil de acesso;

\- RF02: Anonimização de identificadores;

\- RF03: Tratamento de valores ausentes;

\- RF04: Tratamento de duplicidades;

\- RF05: Consulta de dados tributários;

\- RF06: Definição da variável-alvo;

\- RF07: Avaliação do modelo;

\- RF08: Cálculo do score de recuperabilidade;

\- RF09: Revisão humana;

\- RF10: Exibição das limitações e orientações de contestação.



O arquivo PDF contém a descrição, a história de usuário e os critérios de aceite de cada requisito.
